# 🚀 Courier Monitor (Достависта Сканер Заказов)

Монитор заказов для курьеров сервиса "Достависта" с возможностью автоматической фильтрации по **радиусу от курьера** и **минимальной оплате**, а также мгновенной отправкой уведомлений в **Telegram** и **Discord** (на ПК или телефон).

---

## 🛠 Комплектация проекта

В данном репозитории подготовлено **2 готовых решения**:

1. **Android App (Kotlin Native)** — автономное приложение для смартфона на базе `AccessibilityService`. Работает прямо на телефоне без компьютера.
2. **Python PC Script (`python_pc_bot/main.py`)** — скрипт для запуска на ПК через USB-кабель/Wi-Fi и `ADB` (не требует сборки APK).

---

## 📱 Вариант 1: Android Приложение (Kotlin)

### Структура проекта:
- `app/src/main/java/com/courier/notifier/DostavistaMonitorService.kt` — служба спец. возможностей, автоматически считывающая открытый экран "Достависта".
- `app/src/main/java/com/courier/notifier/OrderParser.kt` — парсер расстояний ("1.5 км", "700 м") и стоимости заказов.
- `app/src/main/java/com/courier/notifier/TelegramNotifier.kt` — модуль отправки уведомлений в Telegram.
- `app/src/main/java/com/courier/notifier/DiscordNotifier.kt` — модуль отправки вебуков в Discord.
- `app/src/main/java/com/courier/notifier/MainActivity.kt` — экран настроек (радиус, мин. сумма, токены).

### Как открыть и собрать:
1. Откройте папку проекта в **Android Studio**.
2. Нажмите `Build` -> `Build Bundle(s) / APK(s)` -> `Build APK(s)`.
3. Установите полученный APK-файл на телефон.
4. Откройте приложение, укажите Telegram Bot Token и Chat ID, нажмите **Сохранить**.
5. Нажмите **"Включить службу спец. возможностей"** и активируйте `Courier Monitor` в настройках Android.

## 💻 Вариант 2: Запуск с ПК (Python + ADB)

Если вы не хотите собирать APK, можно запустить готовый скрипт на ПК, пока телефон подключен к компьютеру (по проводу или по Wi-Fi ADB).

### Инструкция по запуску:
1. Включите на телефоне **Отладку по USB** (в разделе "Для разработчиков").
2. Подключите телефон к ПК через USB-кабель.
3. Откройте терминал на ПК и установите зависимости:
   ```bash
   pip install requests
   ```
4. Откройте файл `python_pc_bot/main.py` и укажите в нем ваш `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, желаемый радиус `MAX_RADIUS_KM` и `MIN_PRICE_RUB`.
5. Запустите скрипт:
   ```bash
   python python_pc_bot/main.py
   ```

## 🤖 Как быстро настроить Telegram Бота (1 минута)

1. Откройте Telegram и найдите бота `@BotFather`.
2. Напишите команду `/newbot`, укажите имя и юзернейм для вашего бота.
3. Скопируйте полученный **HTTP API Token** (например: `123456789:ABCdefGHI...`).
4. Для получения твоего **Chat ID** найди бота `@userinfobot` в Telegram, отправь ему команду `/start` и скопируйте числовой `Id`.
5. Нажмите `/start` в созданном тобой боте, чтобы разрешить ему присылать тебе сообщения.
